# НавиКультура / NaviKultura

Информационно-навигационная платформа для ГДК «Кировский».

**Статус:** стартовый каркас и зафиксированное ТЗ, этап 00. Это не производственная версия.

## Назначение

- Посетители открывают информационный экран **через браузер** по маршруту `/screen`.
- Сотрудники редактируют материалы со своих ПК в браузерном кабинете `/editor` (на этапе 00 — **только демонстрационный экран**, без сохранения).
- Центральный сервер планируется установить на `DESKTOP-OBLAKO`, без изменений существующих SMB-ресурсов.
- Автоматические афиши, расписания из таблиц, визуальный конструктор, сохранение, авторизация и публикация будут добавляться последовательно в следующих этапах.

## Состав

`apps/api` — Fastify 5, Node.js 26 LTS; на этом этапе **только безопасные GET API**.

`apps/web` — Vue 3, TypeScript, Vite 8; два адаптивных представления `/screen` и `/editor`.

`docs` — утверждённые требования, архитектура, этапы, эксплуатация, интерфейс и безопасность.

## Локальная разработка (Node.js 26 LTS)

```powershell
npm install
```

Терминал 1 — API:

```powershell
npm run dev:api
```

Терминал 2 — веб-интерфейс:

```powershell
npm run dev:web
```

Ссылки на текущем ПК: `http://localhost:5173/screen`, `http://localhost:5173/editor`, API `http://127.0.0.1:3100/api/health`.

Установленный по умолчанию сервер слушает **только 127.0.0.1**. До появления авторизации и защищённого развёртывания не следует открывать порт API в локальную сеть.

Проверки:

```powershell
npm run check
```

Примечание: `npm install` должен создать `package-lock.json`; после успешной установки lock-файл следует зафиксировать в Git в следующем PR. На этапе 00 сетевые сборки локально не запускались: пакетный реестр недоступен из среды подготовки.
