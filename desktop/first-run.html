ДК «КИРОВСКИЙ» / НАВИКУЛЬТУРА

Первый запуск.

Создайте пароль администратора этого компьютера. После настройки НавиКультура откроется на весь экран.

Экранная клавиатура

Пароль не поставляется вместе с EXE и не отправляется в интернет. Настройки сохраняются в вашем профиле Windows. Для входа используйте пункт «Вход в админку».
