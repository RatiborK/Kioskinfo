# Дизайн-система v0.1

Источник визуального направления: проект «Сайт ДК» (не копирование кода). Почти чёрный `#080808`, тёплый белый `#F4F2EC`, оранжевый и синий акценты, крупная геометрическая типографика, строгая сетка с асимметрией, свободное пространство и выразительные графические блоки. Без постоянного стеклянного/градиентного оформления.

**Временные UI токены:** `--ink: #080808`, `--warm: #F4F2EC`, `--orange: #FF7A1A`, `--blue: #367CFF`. Последние два — рабочие оттенки, сверить с оригинальным проектом «Сайт ДК».

### Экран посетителя

- Full page, правое вертикальное навигационное меню на широких дисплеях.
- Большие зоны касания; текущий раздел выделяется оранжевым.
- Контент размещается в блоках с сеткой; минимум декоративного шума.
- Для узких дисплеев меню адаптируется в сетку; для киосков предустановлены профили 16:9/9:16.
- Медиаконтент не обрезается автоматически без настройки `contain` / `cover`.

### Кабинет сотрудника

- Обычный адаптивный веб-интерфейс, не копия большого киоск-экрана.
- Кнопки «Добавить», «Загрузить», «Предпросмотр»; простая терминология.
- Чёткие статусы: «Изменено», «Сохраняется», «Сохранено», «Не удалось сохранить»; не показывать «Сохранено» до ответа сервера.
- Выбор оформления из галереи шаблонов, «Применить ко всем с наследованием».
- Визуальные редакторы не меняют структуру данных; публикация — отдельная сущность.

### Доступность

- Контраст текста, читаемая типографика, подсветка фокуса, навигация клавиатурой; режимы увеличения и синтеза речи — будущий этап.
