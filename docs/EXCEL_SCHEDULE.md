# Памятка сотруднику: расписание из Excel

**Файл:** `content/schedule/raspisanie.xlsx` на компьютере разработчика; позже — общая папка на сервере ДК.

1. Скопируйте `templates/Расписание_пример.xlsx` в папку `content/schedule` и переименуйте его в `raspisanie.xlsx`.
2. Откройте файл в Microsoft Excel. Первый лист содержит строки, формирующие кнопки.
3. Замените демонстрационные строки реальными данными, сохраняйте исходный столбец ID при изменении названия кнопки.
4. Нажмите Ctrl+S. Кнопки обновятся на `/screen` без перезапуска, обычно в течение 10 секунд.
5. Для удаления кнопки удалите строку. Для добавления — добавьте новую с уникальным ID.
6. Ошибка в XLSX не удалит действующую информацию: поправьте строку, сохраните снова.

| Столбец | Назначение |
|---|---|
| ID | Неизменяемый уникальный код латиницей, например `dance01` |
| Кнопка | Краткое название на сенсорной кнопке |
| Коллектив | Полное наименование на странице |
| Руководитель | ФИО или подпись должности, необязательно |
| Расписание | Дни и время занятий, необязательно |
| Кабинет | Место занятий, необязательно |
| Описание | Подробная информация, необязательно |
| Возраст | Возрастная группа, необязательно |
| Шаблон | `оранжевый`, `синий`, `нейтральный`, либо пусто |
| Повторить стиль | `Да` для наследования предыдущего шаблона, только если поле Шаблон пусто |

**Важно:** переименование файла или папки ломает автоматическое обнаружение. Сохраняйте как `.xlsx` (не `.xls`, `.csv` или `.xlsm`).

В первой версии создаются кнопки и карточки; произвольное оформление и дополнительные блоки будут в Stage 04.
