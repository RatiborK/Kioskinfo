# НавиКультура — требования v0.2 (утверждены к разработке)

**Пилот:** ГДК «Кировский». **Сервер:** постоянно работающий `DESKTOP-OBLAKO` (в сообщении также указан как «olako»). **Доступ:** веб-браузер в локальной сети, без самостоятельного EXE-посетительского клиента.

## Три поверхности

1. **Посетительский экран `/screen`** — полноэкранная адаптивная страница, меню справа, крупные сенсорные зоны; все материалы только из опубликованного состояния.
2. **Кабинет `/editor`** — понятные формы со снимком предпросмотра, автосохранением, шаблонами и доступом по ролям.
3. **Панель администратора `/admin`** — экраны, права, источники, публикации, шаблоны, резервные копии, диагностика.

## Важнейшие правила редактирования

- Сотрудник работает преимущественно **через браузер**; перенос файлов в общую SMB-папку остаётся альтернативным автоматизированным способом.
- Изменение поля формы сохраняется **автоматически**: после короткой паузы ввода (плановый debounce 600–1000 мс), немедленно при потере фокуса, при выборе настройки/галочки; интерфейс сообщает «Сохраняется / Сохранено / Ошибка». Необратимые изменения требуют подтверждения.
- Каждая запись имеет ID, ревизию, автора, дату изменения. Конфликт двух редакторов не должен незаметно перезаписать чужие изменения.
- **Сохранение черновика не равно публикации**: автопубликация может быть настроена для афиш и корректного расписания; сложные страницы публикуются после предпросмотра. Публикуем атомарный проверенный снимок.
- Действующий экран не меняется от повреждённого файла, незаконченной записи или ошибки таблицы.

## Афиши и медиа

- Интерфейс «Загрузить / Удалить / Порядок / Дата показа / Предпросмотр» в браузере.
- Дополнительно можно назначить контролируемую папку `Афиши` на сервере; новые/удалённые файлы синхронизируются. Изолировать папку импорта от файлов, уже принятых в каталог.
- Источники: изображения JPG, PNG, WebP; видео MP4, MOV, AVI, MKV. **Воспроизведение через браузер обеспечивается серверной конвертацией** неподдерживаемых форматов в MP4 (H.264/AAC), с проверкой кодеков и ограничениями размера; исходник сохраняется отдельно.
- Автоматическое слайд-шоу, время кадра, порядок, расписание публикации, дубль-проверка, размеры, миниатюры, портретный/альбомный режим, история публикаций.
- Файлы из внешних источников проходят проверку типа, объёма, расширения и чтения; конвертация выполняется в отдельном процессе с лимитами.

## Расписание и генератор кнопок

- Строка Excel/таблицы соответствует **одной записи** с устойчивым ID. Поля: название кнопки, коллектив, руководитель, занятия, помещение, описание, фото и т.д.
- При появлении новой строки создаётся кнопка, маршрут и карточка; при изменении строки обновляются её данные, **индивидуальная тема кнопки не стирается**.
- Поддерживать работу как в браузерной таблице, так и через импорт `.xlsx` (выбор основной модели владения данными для каждой коллекции).
- `☑ Наследовать оформление образца`: новые кнопки используют один стиль; обновление темы меняет только элементы с наследованием. Исключения доступны.
- Ошибки: дубль ID, неправильное время, пустое обязательное поле, исчезновение файла, повреждённый Excel. Изменения применяются только после проверки.

## Блочный конструктор

- Страница собирается на сетке из типовых блоков: заголовок, текст, кнопки, фото, видео, документ, расписание, каталог коллективов, карта, галерея.
- Автоматическое выравнивание, адаптивная компоновка, отступы, предустановленные стили, копирование блоков, сохранение и откат.
- Полноэкранный (fill-page) экран посетителя, **навигационное меню справа**; редактор с визуальным предпросмотром.
- Темы согласуются со стилем проекта «Сайт ДК»: почти чёрный фон, тёплый белый, оранжевый и синий акценты, асимметрия и афишная типографика. Точные оттенки оранжевого/синего — временные до согласования источника.

## Основные модули

Афиши, календарь событий, расписание, коллективы и руководители, новости, фото, видео, документы, страницы, навигация по зданию, контакты, общий поиск, доступность.

## Поиск и навигация

- Поиск по опубликованным данным с коррекцией опечаток; допустимые синонимы; результаты с категорией, быстрый переход.
- Удобство на сенсорном экране, экранная клавиатура, крупные элементы, озвучивание, контраст и размер шрифта, таймер простоя.
- План здания и маршрут до помещения — отдельный этап после получения точных планов.

## Надёжность

- Обновления через WebSocket с резервным HTTP-проверочным опросом и номером ревизии.
- Последний проверенный опубликованный снимок кэшируется на терминале; сеть пропала — экран остаётся рабочим даже после перезагрузки, если снимок доступен.
- Автозапуск сервера после перезагрузки, мониторинг, резервные копии БД и медиа, журнал изменений и откат.
- Не публиковать реальные данные сотрудников, афиши, ключи, настройки и внутренние IP в открытый репозиторий.
