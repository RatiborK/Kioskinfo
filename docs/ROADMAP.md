# Дорожная карта «НавиКультура»

Каждый этап — отдельная ветка и Draft PR. GitHub CI подтверждает сборку, но не эксплуатационную готовность. DESKTOP-OBLAKO до приёмки не используется.

| Этап | Функция | Статус |
|---|---|---|
| 00 | Архитектура, Vue/Fastify, VS Code HMR | Локальная приёмка PASS |
| 01 | PostgreSQL, аккаунты, редактор страниц | CI PASS; БД ещё не проверена локально |
| 02 | Папка афиш, показ и медиа-каталог | CI PASS, экран принят пользователем |
| 03 | Расписание: Excel → кнопки (исторический кандидат) | Заменён новым решением, не внедрять |
| 03.1 | Браузерный CRUD, автосохранение и публикация расписания | В разработке, требует CI и приёмки |
| 03.2 | Вкладки «Расписание», «Афиши», «Страницы» в кабинете сотрудника | CI и локальная приёмка |
| 04 | Оформление отдельных кнопок | Отклонено: заменено едиными темами посетителя |
| 05 | Восемь готовых тем, отдельная вкладка, предпросмотр и публикация | CI + локальная приёмка |
| 05.1 | Локальный поиск по расписанию, экранная клавиатура, лента афиш и возврат после простоя | CI PASS; локальная приёмка ожидается |
| 05.2 | Лупа с раскрытием поиска, full-page переходы, анимация карточек/афиш | CI + локальная приёмка |
| 05.3 | Редактор без таймера сохранения, вход администратора, документы DOCX/PDF и календарь событий | CI + локальная приёмка |
| 05.4 | Безопасность, О ДК, билеты, 37 коллективов, 30 руководителей, фото/видео и редактируемое наполнение | CI + локальная приёмка |
| 06 | WebSocket, мультиэкран, автономный кеш | План |
| 07 | Windows-служба, HTTPS, резервирование и развёртывание | План |
| 08 | Календарь, карта ДК, OCR, интеграции | План |
