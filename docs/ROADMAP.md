# Дорожная карта разработки

Каждый завершённый этап: отдельная ветка `stage/NN-*`, проверяемые критерии, тесты, PR, интеграция только после приёмки. Незавершённые стадии не обозначать как готовые.

| Этап | Что получаем | Обязательная проверка |
|---|---|---|
| 00 | ТЗ, архитектура, репозиторий, демонстрационный web/API каркас | JSON-валидность, API tests, web typecheck/build в CI |
| 01 | Авторизация, роли, PostgreSQL, публикация черновика, базовое безопасное LAN-развёртывание | Ограничение прав, миграции, backup/restore, реальный вход сотрудника |
| 02 | Веб-загрузка афиш + опциональный контролируемый SMB import, медиа pipeline | Добавление/удаление без перезапуска, некорректный файл не влияет на показ |
| 03 | Расписание, импорт Excel, стабильные ID, автокнопки и карточки | Добавить/изменить/переставить/удалить строки, не потерять темы |
| 04 | Визуальный блочный конструктор, шаблоны, наследование | Копия шаблона и массовая правка без потери данных |
| 05 | Поиск, сенсорный интерфейс, посетительские сценарии | Поиск с опечаткой, клавиатура, доступность |
| 06 | WebSocket, несколько экранов, автономный режим и мониторинг | Потеря сети / перезапуск клиента / восстановление синхронизации |
| 07 | Windows-служба на DESKTOP-OBLAKO, бэкапы, обновления, нагрузочная приёмка | Перезагрузка сервера, восстановление, устойчивость существующих служб |
| 08 | Календарь, навигация этажей, OCR/ИИ и интеграции | Не допускаются непроверенные автоматические публикации |

## Правила «готово»

Работоспособный сценарий + тест + документация + Git commit/PR + результат проверки на подходящем окружении. Тест в лаборатории не доказывает, что сервис реально запущен на DESKTOP-OBLAKO.

**Этап 01 — следующий:** PostgreSQL миграции, учётные записи, авторизация, типизированные схемы API, форма редактирования с debounce/ревизией, версия публикации, установка только в тестовом окружении.
