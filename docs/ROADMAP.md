# Дорожная карта «НавиКультура»

Каждый этап: отдельная ветка, проверка, коммит, Pull Request. Слияние после приёмки. Запуск в лаборатории не означает установку на DESKTOP-OBLAKO.

| Этап | Содержание | Статус |
|---|---|---|
| 00 | Архитектура, UI-прототип, основа API | Ветка опубликована, требует PR и CI |
| 01 | PostgreSQL, авторизация, роли, редактор черновика, публикация | Кандидат на лабораторную приёмку |
| 02 | Афиши, загрузка JPG/PNG/WebP, видео MP4, синхронизация папки | Кандидат: реализация и CI, без полевой приёмки |
| 03 | Excel, строка → кнопка, карточки, расписание | План |
| 04 | Визуальный блочный редактор, шаблоны, наследование стиля | План |
| 05 | Поиск, сенсорный UX, доступность | План |
| 06 | WebSocket, мультиэкран, автономный кеш | План |
| 07 | Windows-служба, локальный HTTPS, восстановление, нагрузочная проверка | План |
| 08 | Календарь, карта ДК, OCR/ИИ, интеграции | План |

**Запрещено объявлять этап принятым до тестов на целевой версии Node и ручной демонстрации, отмеченной в STAGE01_ACCEPTANCE.md.**
