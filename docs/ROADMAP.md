# Дорожная карта «НавиКультура»

Каждый этап — отдельная ветка и Draft PR. GitHub CI подтверждает сборку, но не эксплуатационную готовность. Никаких установок на DESKTOP-OBLAKO до полного тестирования локальной версии.

| Этап | Функция | Статус |
|---|---|---|
| 00 | Архитектура, Vue + Fastify, VS Code HMR | Локальная приёмка PASS |
| 01 | PostgreSQL, аккаунты, редактор и публикация | CI PASS, БД ещё не принята локально |
| 02 | Папка афиш, медиа-каталог, синхронизация, просмотр без БД | CI PASS, экран подтверждён пользователем |
| 03 | Excel: строка → кнопка → карточка, наследование темы | Кандидат к CI и локальной приёмке |
| 04 | Настраиваемые шаблоны, блочный конструктор | План |
| 05 | Поиск по коллективам, доступность, сенсорный UX | План |
| 06 | WebSocket, мультиэкран, автономный кеш | План |
| 07 | Windows-служба, HTTPS, резервирование, внедрение | План |
| 08 | Календарь событий, карта ДК, OCR и интеграции | План |
