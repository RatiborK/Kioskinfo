# Безопасность

- Repo публичный: никакого `DATABASE_URL`, секретов, паролей, выгрузок пользователей, backup или данных работников в Git.
- API слушает только loopback, пока не настроен и не протестирован HTTPS reverse proxy.
- Сессии: случайный токен, SHA-256 его значения в БД, cookie HttpOnly/SameSite=Strict, `Secure` только на HTTPS.
- Изменяющие запросы требуют JSON + заголовок X-Navikultura-Action, проверку Origin по явному `EDITOR_ORIGIN`.
- Пароли хранятся в виде scrypt хэшей с солью.
- Права проверяются на сервере; скрытие кнопок в UI не является авторизацией.
- Черновик и опубликованный снимок разделены, публикует пока только admin.
- Первая реализация лимита логинов в памяти одного процесса. Перед масштабированием на несколько API-инстансов — перевести в общую БД/Redis.
- Текущий stage 01 предназначен для тестовой эксплуатации только на loopback, не открыт в LAN и не прошёл внешний аудит безопасности.
- `COOKIE_SECURE=true` и точный HTTPS `EDITOR_ORIGIN` — обязательные условия будущего LAN-режима.
