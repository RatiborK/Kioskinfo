# Stage 03.2 — вкладки кабинета сотрудника

## Цель

Вместо одной длинной страницы редактор показывает одну рабочую область за раз.

- **Расписание** — создание, редактирование, автосохранение и публикация карточек (основная вкладка)
- **Афиши** — загрузка и удаление изображений, просмотр медиакаталога
- **Страницы** — существующие текстовые страницы, редактор черновиков и публикация

## Навигация

- Адрес `/editor` открывает «Расписание»
- `/editor?tab=posters` открывает «Афиши»
- `/editor?tab=pages` открывает «Страницы»
- Поддерживаются стрелки влево/вправо, Home/End на панели вкладок
- Активная вкладка выделена, остальные блоки скрыты, но не уничтожаются (Vue `v-show`)
- При смене вкладки редактор пытается сохранить незавершённую правку; ошибка сохранения блокирует переключение
- При обновлении вкладки браузера загружается соответствующий раздел по параметру URL

## Проверка на ПК разработчика

1. Обновить ветку `stage/03-2-editor-tabs` и выполнить `npm.cmd run check`
2. Запустить `npm.cmd run dev:preview` и `npm.cmd run dev:web`
3. Войти в `http://127.0.0.1:5173/editor` с локальным паролем из терминала API
4. Убедиться, что открыто только «Расписание», а афиши и страницы не отображаются ниже
5. Создать карточку и переключиться на «Афиши»; убедиться, что черновик сохранился
6. Вернуться в «Расписание», проверить содержимое и опубликовать карточку
7. Перейти на «Страницы», изменить текст, перейти в другой раздел и убедиться в сохранении
8. Открыть прямую ссылку `/editor?tab=pages`, проверить переход после входа
9. Проверить переключение с клавиатуры и отображение на узком экране
10. Переключиться на экран посетителя: функциональность `/screen` не должна измениться

**Пока не выполнено:** визуальная проверка и проверка взаимодействия пользователя на Windows. Никаких изменений в продакшн-сервере не проводится.
