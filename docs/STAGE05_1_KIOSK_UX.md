# Stage 05.1 — поиск и удобство сенсорного терминала

## Реализовано
- Локальный поиск по **названию кнопки**, коллективу, руководителю, времени, номеру кабинета, возрасту и описанию.
- Не требуется отправка текста поиска на сервер или подключение сторонних сервисов: фильтрация опубликованных карточек выполняется в браузере.
- Поиск учитывает русские буквы, регистр, ё/е, пунктуацию, несколько слов и типичную ошибку английской раскладки.
- Дополнительная экранная клавиатура РУ/EN, крупные кнопки, пробел, стирание, очистка, скрытие. Нативная клавиатура системы также может использоваться.
- Отображение количества найденных карточек, удобное пустое состояние.
- Афиши: миниатюры для быстрого выбора, до шести видимых за раз; полное изображение сохраняет пропорции и не обрезается.
- Автопрокрутка афиш ставится на паузу после ручного выбора примерно на 12–16 секунд; видео не переключается посреди воспроизведения таймером.
- Возврат к «Афише» после 3 минут отсутствия касаний и нажатий. Содержимое поиска и открытая карточка при возврате очищаются.
- Унифицированные стили восьми тем и крупные сенсорные элементы.
- Восемь браузерных unit-тестов: пять тестов поиска и три теста окна миниатюр/таймера простоя, помимо API-тестов.

## Данные не меняются
Нет новых миграций API/БД. Существующие `content/posters`, `content/schedule/records.json` и `content/settings/visitor-theme.json` не переписываются.

## Приёмка на ПК
1. Остановить локальные API и Vite через Ctrl+C.
2. Переключиться на `stage/05-1-visitor-search-touch`; `npm.cmd install --no-audit --no-fund` (обновляет npm lock, если необходимо); `npm.cmd run check`.
3. Запустить VS Code задачу `Navikultura: Start API + Web`.
4. На `/screen` выбрать «Расписание», попробовать поиск по названию, фамилии руководителя, кабинету, нескольким словам и слову с ё.
5. Открыть экранную клавиатуру, ввести слово по-русски, переключить на EN, очистить, закрыть.
6. Открыть найденную карточку и вернуться назад: список и фильтр должны остаться.
7. Проверить пустой запрос и отсутствие результатов: появится пояснение и действие «Показать все».
8. Добавить в `content/posters` 2–4 актуальные афиши, вернуться к «Афише», проверить миниатюры и переключение касанием.
9. После ручного выбора убедиться, что изображение не переключается немедленно таймером.
10. Вернуться к «Расписанию», оставить экран без действий более 3 минут: откроется «Афиша».
11. Проверить все восемь тем; выполнить проход для 1920×1080 и 1366×768, экранной клавиатуры и 200% масштаба.
12. Изменить расписание/афиши в редакторе, убедиться, что функциональность сохраняется.

## Ограничения
- Поиск пока только по коллективам и расписанию; афиши доступны визуально по миниатюрам.
- Версия не содержит распознавание речи и автоматическое построение маршрута по зданию.
- Виртуальная клавиатура не заменяет системные специальные возможности Windows.
- Локальная успешная сборка и CI не заменяют испытания на реальном сенсорном мониторе.
- Поиск не передаёт запросы на сервер; браузер обрабатывает только полученные опубликованные записи.
