# Stage 05.2 — полноэкранные переходы и раскрывающийся поиск

## Изменение интерфейса
- В шапке **каждого** раздела появится кнопка с иконкой лупы (сенсорная цель 54–60 px).
- В обычном состоянии поиск **скрыт**, список расписания занимает всю доступную ширину.
- Нажатие лупы из «Афиши» или другого раздела открывает **«Расписание» + поиск**.
- Внутри «Расписания» или «Коллективов» повторное нажатие скрывает поиск и сбрасывает введённый фильтр.
- Поиск содержит экранную клавиатуру и прежние условия фильтрации. При закрытии поиск не влияет на список.
- Переход по меню заменяет **всю основную область посетительской страницы** (логотип, содержимое, подвал) одним full-page slide/fade через `<Transition mode="out-in">`. Правое меню не перемещается.
- Переход «каталог → карточка коллектива → каталог» имеет отдельную мягкую анимацию.
- Афиши перекрывают друг друга на время crossfade без белой вспышки, включая переключение картинок и видео.
- Фильтрация карточек использует Vue `TransitionGroup` для плавного появления и перестановки.
- Меню и кнопка поиска имеют плавные наведения, нажатия и индикатор активного раздела.
- Настройка операционной системы `prefers-reduced-motion:reduce` отключает необязательное движение.
- При смене раздела сбрасывается прежний фильтр, чтобы другой посетитель не увидел чужой запрос; таймер 3 минут по-прежнему возвращает к афише.
- При переходе фокус клавиатуры переводится на заголовок/поиск/карточку, когда прежний элемент удаляется.

## Почему так
Используется официальная возможность Vue 3 `<Transition>` с `mode="out-in"`. Анимация содержимого занимает около 0.7 с с учётом выхода и входа; кнопка поиска раскрывает блок примерно за 0.38 с. Нет сторонних анимационных библиотек и тяжёлых скриптов, только transform/opacity CSS. В качестве ориентиров использованы Vue Transition Guide и MDN prefers-reduced-motion.

## Проверки
1. Запустить обновлённую ветку в VS Code и открыть `http://127.0.0.1:5173/screen`.
2. Из «Афиши» нажать лупу: целиком сменится страница, отобразится «Расписание» с раскрытым поиском; строка получает фокус.
3. На странице расписания нажать лупу повторно: поиск плавно схлопывается, список снова полный.
4. Раскрыть поиск, ввести название коллектива, открыть найденную карточку, вернуться назад — убедиться, что заголовок и содержимое анимируются, фильтр сохраняется.
5. Пройти «Афиша» → «Коллективы» → «О ДК» → «Контакты»; убедиться, что логотип/подвал движутся вместе с основной страницей, меню остаётся.
6. Проверить переход между двумя афишами с ручными стрелками и миниатюрами: нет пустого кадра.
7. Проверить поиск с экранной клавиатурой, активный индикатор меню, плавность на мониторах 1920×1080 и 1366×768.
8. В Windows отключить эффекты анимации (или включить предпочтение reduced motion) — все необязательные переходы должны стать мгновенными.
9. Проверить работу с клавиатурой Tab/Enter/Esc; Escape пока не используется для закрытия (это отдельный возможный UX-штрих).
10. Оставить терминал без действий на 3 минуты; автоматический возврат на афишу сохраняется.
11. Проверить вкладку тем и редактор: изменений API и БД нет, материалы остаются прежними.

## Ограничение приёмки
CI подтверждает компиляцию Vue, TypeScript, unit-тесты поиска и API. Фактическую плавность, 60 FPS и отображение на целевом Windows GPU необходимо проверить вручную; до этого merge в `main` не разрешён.
