# Stage 05.6 — планы ДК, светлая тема, клавиатура и профилактические материалы

## Что изменилось

### Тема «Стиль сайта ДК»
Официальная гамма повторяет визуальное направление предоставленного скриншота сайта: **белый фон, крупная чёрная типографика, яркий оранжевый и фирменный синий**. Изменён существующий preset `dk`, другие семь тем и нейтральный интерфейс админа не затронуты. В редакторе «Темы оформления» можно выбрать и опубликовать тему.

### Поэтажная навигация
Вкладка посетителя **«Навигация»** показывает три изображения схем, извлечённые из оригинального файла `план дк.vsdx`:
- `floor-1.webp` — схема **первого этажа** (надпись присутствует на оригинале).
- `floor-2.webp` — схема верхнего уровня, но **этаж на оригинале не подписан**.
- `floor-3.webp` — похожая схема с дополнительными значками, номер этажа **нужно уточнить**.

На посетительской странице есть переключение схем, управление масштабом, список проверенных точек, фильтр типа помещений, выбор точки по нажатию. В кабинете сотрудника **«Наполнение ДК → Планы ДК»** есть кликабельная схема для добавления точки, её категории, названия, координат и текстового описания. Изменения идут через обычный механизм «черновик → опубликовать». Точки намеренно пустые до проверки: нельзя выдавать незнакомую комнату за кассу или рисовать придуманный маршрут эвакуации.

**Это справочный план здания, а не утверждённый план эвакуации.** Не следует использовать его вместо обязательных информационных знаков и схем на стенах.

### Безопасность
Добавлены две самостоятельные памятки к уже существовавшим 15:
- **Профилактика экстремизма**: понятие экстремизма, примеры противоправных форм, куда сообщать, правовая ответственность, общие нормативные основания.
- **Безопасность транспорта и инфраструктуры**: последствия поджогов и повреждения инфраструктуры, закон и ответственность, безопасное поведение при обнаружении угроз.

В каталог включены **семь сохранённых иллюстраций**, воспроизводящих пользовательские материалы:
1. `А4-1.pdf`, 1 стр. — «Экстремизму — нет», виды и сообщение об экстремизме.
2. `A4 - 2.pdf`, 1 стр. — ответственность и статьи закона.
3. `Что_такое_экстремизм_...pdf`, страницы 1–4 — информационный выпуск Западно-Сибирской транспортной прокуратуры.
4. `хайп 2.png` — плакат о последствиях противоправных действий в отношении объектов транспорта.

Ресурсы показываются в собственной галерее/просмотрщике без внешних вкладок. **Текст и изображения оригинальных листовок сохранены, но их правовые формулировки не объявлены безоговорочно актуальными**. При написании публичных тезисов использована действующая статья 281 УК РФ: основной состав предусматривает лишение свободы 10–20 лет, часть 2 — 12–20 лет, часть 3 — 15–20 лет либо пожизненное лишение свободы. Это квалифицируется по обстоятельствам конкретного дела. Источник: https://www.consultant.ru/document/cons_doc_LAW_10699/26760b317cab8b7c84154df406492379d8f6abf1/
Также учтены 114-ФЗ и КоАП РФ (20.3, 20.3.1, 20.29, 13.53); актуальность нормативной справки необходимо периодически проверять.

### Клавиатура на сенсорной панели
- Значок **⌨** постоянно расположен рядом с лупой в верхней панели на любой странице посетителя. При нажатии открывает общий поиск с русско-английской виртуальной клавиатурой.
- Виртуальная клавиатура поддерживает русские/латинские буквы, **цифры**, пробел, знаки препинания, удаление.
- Экран входа в админку также имеет клавиатуру для логина и пароля.
- В полноэкранном окне Muzaticket есть кнопка **«Клавиатура»** и инструкция для Windows. **JavaScript не может записывать текст во ввод чужого iframe** из-за same-origin policy. Для фактического ввода в билетном виджете требуется системная сенсорная клавиатура Windows, которая открывается при фокусе на поле в настроенной Windows-учётной записи киоска. Это должно проверяться на реальном устройстве.

### Локальный вход администратора
- Логин **admin** остаётся установленным в локальном preview-режиме.
- Для пароля разработчика теперь поддерживается индивидуальная `.env.local`, игнорируемая Git:
  `NAVIKULTURA_DEV_PASSWORD=<user-supplied-dev-password>`
- Значение читается локальным API при старте, преобразуется в парольный хэш и **не выводится в терминале**.
- Минимум 8 символов разрешён **только для localhost preview**, а для реальной эксплуатационной сети нужен другой более сильный пароль (12+ и индивидуальный).
- **В GitHub пароли и пользовательские фото/планы не хранятся.** Настройки действуют после перезапуска API; на PostgreSQL production не влияют.

## Как подключить медиаматериалы (обязательно)
В этом этапе медиа распространяются отдельным ZIP `Navikultura_Stage056_Media.zip`, так как содержит исходные пользовательские планы ДК и информационные листовки. Он устанавливается локально **после переключения на ветку** `stage/05-6-floormap-site-theme-awareness`.

Распаковать архив в корень репозитория (`C:\Users\<WindowsUser>\Navikultura`), не удаляя предыдущие материалы. Внутри архива относительные пути:
- `apps/web/public/assets/navigation/floor-[1-3].webp`
- `apps/web/public/assets/safety/*.webp`

Файлы добавлены в `.gitignore`, чтобы не загружать потенциально чувствительные планы здания в публичный GitHub. **Не публиковать эти планы в открытом интернете без разрешения учреждения.**

## Локальная приёмка
1. Остановить старые серверы. Обновиться до ветки `stage/05-6-floormap-site-theme-awareness`.
2. Распаковать ZIP из `Downloads` в корень репозитория; проверить `Test-Path apps/web/public/assets/navigation/floor-1.webp` и `Test-Path apps/web/public/assets/safety/sabotage.webp`.
3. Создать `.env.local` с `NAVIKULTURA_DEV_PASSWORD` только локально. Перезапустить API (без него пароль не изменится).
4. `npm.cmd install --no-audit --no-fund`, `npm.cmd run check`; запустить `Navikultura: Start API + Web`.
5. Открыть экран `/screen`, проверить **белую тему** и другие семь тем (при необходимости выбрать в редакторе темы `dk`).
6. Вкладка **«Навигация»**: проверить все 3 схемы, кнопки +/−, естественные пропорции и надпись о неподтверждённых этажах.
7. В `/editor?tab=culture` → **«Планы ДК»** нажать на место на 1-м этаже; создать тестовую отметку, сменить категорию и название, **сохранить и опубликовать**.
8. Проверить новую точку на экране посетителя и поиск по названию помещения (автоматический переход к нужной схеме).
9. На любой странице нажать значок ⌨; ввести, например, `Кировский` и `кабинет 39` через виртуальную клавиатуру.
10. Войти в админку через локальную учётную запись и проверить ввод букв и цифр через экранную клавиатуру.
11. Проверить билетное окно Muzaticket и **системную клавиатуру Windows** при касании поля. Не вводить реальные платёжные данные при тестировании с незнакомой конфигурацией.
12. Вкладка «Безопасность»: найти «Экстремизм» и «Безопасность транспорта», проверить все 7 иллюстраций в полноэкранном просмотре, длинный текст и ссылки на нормы в пояснениях.
13. Проверить работу на реальном экране 1366×768 и 1920×1080. Запуск Edge fullscreen — отдельная задача VS Code из Stage 05.5; полноценное ограничение Windows Assigned Access требует отдельной приёмки.

## Ограничения
- Схемы извлечены из файлов пользователя; у двух изображений **не подтверждены номера этажей**.
- Кнопка клавиатуры в Muzaticket показывает подсказку, а не программно управляет системной клавиатурой Windows: это ограничение безопасности браузера. В production требуется настройка Windows Touch Keyboard.
- Медиа локально ставится из отдельного ZIP и отсутствует в Git; CI проверяет код, а не наличие медиа у пользователя.
- Юридические материалы информационные и не заменяют консультацию юриста или утверждённые инструкции ДК.
- Смена пароля **только локального preview-администратора**; для производственной базы пользователей нужен отдельный механизм.
