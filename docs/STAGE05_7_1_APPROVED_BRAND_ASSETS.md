# Stage 05.7.1 — единый SVG-знак ДК «Кировский» для НавиКультуры и печати

## Изменения

### Что утверждено
Пользователь согласовал **геометрию черных, оранжевой и голубой деталей** логотипа по предоставленному изображению. Предыдущий самодельный рисунок символа Stage 05.7 отвергнут. В этом этапе используется новая **чистая векторная трассировка пяти отдельных многоугольников с сохранением белых промежутков**.

**Источник для веб-приложения:** `apps/web/public/brand/dk-kirovsky-symbol.svg`.

**Компонент:** `apps/web/src/components/DkLogo.vue` показывает именно этот файл, а не перерисованный геометрический символ. Название «КИРОВСКИЙ / ДВОРЕЦ КУЛЬТУРЫ / КРАСНОЯРСК» оформлено текстом в компоненте. Он используется в шапке экрана посетителя, кабинете сотрудника и восьми предпросмотрах тем. Логотип цветной во всех темах, с белой подложкой, не наследует тематическую окраску двухцветных значков меню.

**Фавикон браузера**: `/brand/dk-kirovsky-symbol.svg`; заголовок вкладки `ДК «Кировский» — НавиКультура`.

### Один архив для других сервисов и типографии
В разговоре предоставлен `DK_Kirovsky_Brand_05_7_1.zip`. Он содержит:
- `dk-kirovsky-symbol.svg` — основной прозрачный цветной вектор.
- `dk-kirovsky-horizontal.svg` — цветной знак + название учреждения и «Красноярск», надписи переведены в векторные контуры (не требует установленных шрифтов).
- `dk-kirovsky-symbol-black.svg`, `dk-kirovsky-symbol-white.svg` — монохромные версии для однокрасочной печати / тёмного фона.
- `dk-kirovsky-symbol-3000px.png`, `dk-kirovsky-horizontal-3000px.png` — PNG с прозрачным фоном.
- `dk-kirovsky-symbol-vector.pdf`, `dk-kirovsky-horizontal-vector.pdf` — векторные PDF **в RGB, НЕ PDF/X**.
- `README_ДЛЯ_ПЕЧАТИ.txt` — инструкции.

Цвета знака: **#080808** (чёрный), **#FF7900** (оранжевый), **#0874FF** (голубой). Не искажать пропорции и не удалять зазоры между частями символа. Перед офсетной печатью согласовать у типографии нужный CMYK-профиль, особенности материала и стандарт PDF/X. Мастер-вектор сделан по согласованной графике; горизонтальная надпись — новая типографическая композиция, до внешнего массового применения следует согласовать её с учреждением.

**Важно:** оригинальные материалы ДК и связанные пользовательские папки `content` в GitHub не выгружались. В репозитории хранится только публичный бренд-символ без внутренних планов.

### Windows bugfix в Stage 05.7
Тест `branding.test.ts` требовал точный символ перевода строки `\n`, поэтому на Windows с `CRLF` падал, хотя в CI Linux проходил. Теперь файлы CSS нормализуются по концам строк перед анализом, а тесты подтверждают источник SVG, favicon и три фирменных цвета.

### Проверка
1. Из локальной ветки 05.7 открыть чистый рабочий каталог и выполнить `git fetch origin` / `git switch --track origin/stage/05-7-1-approved-brand-kit`.
2. `npm.cmd run check` — TypeScript API/web, unit tests, production builds.
3. Проверить `GET http://127.0.0.1:5173/brand/dk-kirovsky-symbol.svg` — должен быть HTTP 200 с SVG.
4. `/screen`, `/editor` и `/editor?tab=themes`: должен показываться **один и тот же** утверждённый символ, без старого неверного знака.
5. Убедиться, что все 8 двухцветных SVG-иконок меню остаются темо-зависимыми и без рамок.
6. Открыть `/api/public/culture`, сверить ранее сохранённые числа коллективов, руководителей и памяток. Никаких пересозданий базы не требуется.
7. Оценить читаемость горизонтальной подписи и пропорции знака на 1366×768 и 1920×1080; при необходимости отрегулировать только CSS, не саму графику.
8. В типографии проверить цветопробу до печати на большом тираже.

`apps/api`, `content/culture`, черновики, опубликованные афиши, события, документы, авторизацию, PostgreSQL, сервис Muzaticket, маршрутизацию и Windows Assigned Access. `main` и `DESKTOP-OBLAKO` не затрагиваются.
