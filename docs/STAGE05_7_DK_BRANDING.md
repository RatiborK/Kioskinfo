# Stage 05.7 — фирменный знак ДК и двухцветные SVG-иконки

## Цель

Оформить посетительский экран в стилистике Дворца культуры «Кировский», при этом **сохранить существующее наполнение, работу редактора и локальный API**. Этап создан поверх стабильного hotfix `05-6-2-local-preview-password` (локальный вход admin работает).

## Изменения

### Логотип
- `apps/web/src/components/DkLogo.vue`: локальное векторное воспроизведение присланного пользователем логотипа «КИРОВСКИЙ — ДВОРЕЦ КУЛЬТУРЫ». Угловатая буква «К», чёрная надпись и оранжево-синие акценты.
- Используется и на **всех посетительских страницах**, и в **шапке кабинета сотрудника**.
- На тёмных темах сохранена белая подложка: фирменные цвета логотипа намеренно не меняются вместе с темой.
- Логотип — **векторная адаптация по предоставленному скриншоту**, а не утверждённый исходный мастер-файл организации. При получении оригинального SVG логотип можно заменить в одном компоненте без изменений остального интерфейса.

### Значки меню
- `apps/web/src/components/KioskMenuIcon.vue`: все восемь символов — **SVG**, никакого Emoji или Unicode в самих кнопках меню.
- **Афиша**: сохранён мотив звезды, **Календарь событий**: сохранена сетка календаря.
- **Коллективы**: театральные маски, **Документы ДК**: документ с печатью, **Безопасность**: щит с галочкой, **О ДК**: фасад учреждения, **Контакты**: контактная карточка, **Навигация**: схема с меткой.
- Рамки и фон **не рисуются вокруг самих иконок**. Разделительные линии между пунктами меню сохранены.
- Две раздельные краски: `--nav-icon-primary` и `--nav-icon-secondary`, активное/hover-состояние — `--nav-icon-primary-active`, `--nav-icon-secondary-active`.
- Все **восемь** опубликованных тем определяют собственные пары цветов, а не один общий цвет для всех. Контраст подбирался с учётом светлой/тёмной основы.

### Редактор тем
- Теперь карточки пресетов и большой предпросмотр показывают **настоящий логотип ДК и SVG-значки** с цветами именно этой темы.
- Устаревшая подпись «Расписание» из визуального предпросмотра удалена: этот раздел ранее объединён с коллективами.
- Механизм сохранения и публикации тем не менялся.

## Локальная приёмка

1. Остановить терминалы API и Web через `Ctrl+C`; не удалять `content`, `.env.local`, `node_modules` или пользовательские изображения.
2. Перейти на `stage/05-7-dk-brand-bicolor-svg`, выполнить `npm.cmd run check`.
3. Запустить `npm.cmd run dev:preview` и `npm.cmd run dev:web` **в разных терминалах**. Использовать полный путь `C:\Program Files\nodejs\npm.cmd`, если у VS Code ограничен `PATH`.
4. Проверить `http://127.0.0.1:3100/api/health`, затем `/api/public/culture`. Ожидаемый ранее опубликованный каталог: **37 коллективов, 30 руководителей, 17 памяток**, ревизия пользователя может быть выше 3.
5. Открыть `http://127.0.0.1:5173/screen`. Убедиться, что вместо «Н» и «НАВИКУЛЬТУРА» отображается логотип ДК «КИРОВСКИЙ — ДВОРЕЦ КУЛЬТУРЫ».
6. Проверить восемь двухцветных SVG-иконок, отсутствие рамок; «Афиша» по-прежнему узнаётся по звезде, календарь — по сетке.
7. `/editor?tab=themes`: проверить цвет каждой иконки в миниатюрах и большом предпросмотре, выбрать тему, сохранить черновик и опубликовать. Логотип при смене темы остаётся фирменным и читаемым.
8. Проверить кнопки, поиск, клавиатуру, афишу, календарь, коллективы и навигацию без регрессий на **1920×1080 и 1366×768**.
9. `/editor?tab=culture`: убедиться, что все материалы и возможности редактирования остаются на месте.
10. Не изменять систему ДК `DESKTOP-OBLAKO`; Draft PR остаётся открытым до проверки.

## CI

В `apps/web/src/utils/branding.test.ts` проверяется наличие всех SVG-вариантов, цветов каждой темы, отсутствие старой символьной иконографии в меню, доступность логотипа на двух экранах и соответствие предпросмотра.

Тесты и успешная сборка **не заменяют визуальный осмотр** на физической панели и не подтверждают идентичность векторной адаптации утверждённому мастер-логотипу.
