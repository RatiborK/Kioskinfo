# Stage 05.8.2 — выбор двух цветов ДК, встраивание видео, отступы меню

## 1. Цвета темы «Стиль сайта ДК»
В редакторе `/editor?tab=themes` при выборе карточки темы `dk` отображаются два нативных color-picker (цветовой круг/палитра Edge):
- **Основной фон** — исходно `#2c3e50`;
- **Движущееся световое пятно** — исходно `#4ca1af`.

Превью изменяется сразу при выборе. Кнопка «Применить цвета» отправляет авторизованное POST на `/api/editor/theme/dk-colors` с обоими шестизначными HEX и ожидаемой ревизией. Только admin. Ревизионный конфликт возвращает 409; HTML, CSS и небезопасные строки отвергаются. На публичном `GET /api/public/theme` возвращаются `dkBackground`/`dkGlow`; посетительский экран применяет CSS-переменные раз в 10 секунд, не перезапуская анимацию, потому что её элемент принадлежит постоянному `main.screen-shell`.

Цвета карточек, вторичного текста, линий и чёрных частей логотипа автоматически рассчитываются исходя из яркости фона. Оранжевые и синие фирменные цвета не меняются. Другие семь тем не затронуты.

Хранение: `content/settings/visitor-theme.json` для локального preview (старые файлы совместимы) и **новая миграция** `apps/api/migrations/007_dk_palette.sql` для PostgreSQL. Не менять ранее выполненные миграции.

## 2. Видео
Раньше `MediaViewer.vue` передавал обычные URL видеосайтов в iframe, из-за чего внутри окна открывалась вся страница. Теперь `video-sources.ts` принимает только конкретные ссылки на ролики и строит embed-URL:

- YouTube: `/watch?v=…`, `/shorts/…`, `youtu.be/…` → `youtube-nocookie.com/embed/…`. Документация: https://developers.google.com/youtube/player_parameters
- RUTUBE: `/video/32hex/`, `/play/embed/32hex`, приватное `/video/private/32hex/?p=…` → `rutube.ru/play/embed/32hex`, с безопасным ключом. Документация: https://rutube.ru/info/embed/
- VK Видео: `/video-OWNER_ID_VIDEO_ID` либо официальная `/video_ext.php?oid=…&id=…` → встраиваемый `video_ext.php`.

В iframe разрешены сценарии, но запрещены popup и top-level navigation (sandbox); кнопка закрытия остаётся внутри НавиКультуры. Некоторые ролики не позволяют embed по настройке автора: в этом случае локальная копия возможна **только при наличии прав на использование**. HTML5 `<video>` отображает локальный файл в том же модальном окне, с управлением воспроизведением.

### Загрузка локальных видео
В `/editor?tab=culture` → «Коллективы» или «О ДК» добавлен выбор локального файла MP4/WebM до **48 МиБ**. Клиент отправляет бинарный `application/octet-stream` на `POST /api/editor/culture/video` с сеансом сотрудника и CSRF-заголовком. Сервер проверяет роль admin/editor, размер, сигнатуру MP4 `ftyp`/WebM EBML, тип и заменяет имя UUID. Затем возвращает путь вида `/api/public/culture/video/<uuid>.mp4`. Загрузка не публикует черновик автоматически: сотрудник сохраняет каталог, затем администратор публикует.

На `GET /api/public/culture/video/:name` сервер безопасно обслуживает только GUID-файлы, с MIME `video/mp4` или `video/webm`, заголовками `Accept-Ranges`, `Content-Length` и ответом `206 Partial Content` для перемотки.

Файлы хранятся в `content/culture/videos` и не попадают в репозиторий Git. Для эксплуатации создать резервирование и проверить свободное место. Не использовать локальный `file://` браузера. Файлы после удаления ссылки остаются на диске до отдельной администраторской очистки.

## 3. Меню
Пунктам бокового меню добавлен левый отступ `18–26px`, фиксированная колонка для номера `01`, отступ справа. Оранжевая линия больше не накладывается на цифры. В мобильном варианте отступы адаптируются к нижнему индикатору.

## Проверка
1. `npm.cmd run check` (проверка TS/Vue, тесты API, security и сборка).
2. В режиме `dk` выбрать светлый и тёмный фон, новый цвет пятна и нажать «Применить цвета». Проверить корректный контраст текста/логотипа и отсутствие прыжков пятна между разделами.
3. Повторно открыть редактор и `/screen`; цвета должны сохраниться.
4. Открыть коллектив и видеопрогулку ДК: ссылки VK, YouTube, RUTUBE должны открывать плеер, не страницы. Запрещённые URL не должны открываться.
5. Загрузить небольшой легальный MP4/WebM, сохранить и опубликовать; воспроизведение, перемотка, закрытие. Невалидные расширения и подписи должны отвергаться.
6. Проверить отступ пункта «01 Афиша» при активной полоске и наведении на экранах 1920×1080 / 1366×768 и узком окне.
7. В реальном Edge Assigned Access проверить, что внутри embed нельзя перейти на сайт; дополнительно проверить браузерное ограничение autoplay/платформенных iframe (CI это не проверяет).

**Ограничения**: код и CI не доказывают работоспособность конкретных роликов: встраивание может быть заблокировано внешним видеосервисом, сетью или настройками автора. Полный контроль навигации обеспечивается Windows Assigned Access.
