# Stage 05.9 — один переносимый Windows EXE для сенсорного терминала

## Комплект

`Navikultura-0.4.0-Windows-x64.exe` — один переносимый исполняемый файл Windows x64, сформированный через `electron-builder` target `portable`.

Внутри: Electron (Chromium), собранный Vue 3 интерфейс, Fastify API, локальный каталог/афиши/документы/видео, офлайн-редактор, интерфейс посетителя. После двойного щелчка приложение самостоятельно запускает сервер на случайном **127.0.0.1 порту** (наружные подключения отсутствуют), открывает окно **fullscreen+kiosk**, сразу показывает `/screen`. Сторонние вкладки и окна из интерфейса заблокированы.

**Первый запуск:** вместо заранее известного пароля выводится экран создания пароля администратора (минимум 12 символов). Там есть **встроенная сенсорная RU/EN клавиатура**, регистр, цифры, символы и удаление. После создания пароля открывается посетительский экран. Админка вызывается из нижнего меню, логин `admin` и придуманный пароль.

**Без мыши и физической клавиатуры:** прокрутка пальцем по страницам, свайпы между разделами, отдельный свайп афиш, нажатия по кнопкам от 44 пикселей, жесты внутри документов и карт сохраняются; текстовые поля редактора вызывают Windows OSK при касании. Для покупки билетов кнопка «Клавиатура Windows» через защищённый IPC — больше не требуется внешний `node tools/kiosk-windows-keyboard.cjs`.

## Где сохраняются данные

На каждом терминале — **отдельное локальное хранилище**, расположенное в Windows userData приложения (обычно `%APPDATA%\НавиКультура\data\`). Оно остаётся после замены EXE на новую версию.

- `state/admin.json` — scrypt хеш пароля, никогда не содержит открытый пароль;
- `state/pages.json`, `state/audit.jsonl` — тексты страниц и журнал;
- `schedule/records.json`, `events/events.json`, `settings/visitor-theme.json`, `culture/catalog.json`;
- `posters/`, `documents/`, `culture/images/`, `culture/videos/` — загруженные файлы.

Выполняйте регулярное резервное копирование папки `data` после закрытия приложения. Файлы нельзя класть внутрь EXE/ASAR, поскольку там они не сохранятся при замене бинарника. Не редактируйте хранилище вручную.

Внимание: это **автономный режим одного компьютера**, а не синхронизированная локальная сеть. Отдельные EXE на разных ПК не получают публикации с общего сервера без дополнительного режима подключения. Билеты Muzaticket, внешние VK/RUTUBE/YouTube и другие удалённые ссылки требуют сети; автономные страницы/загруженные локальные видео работают без неё.

## Как собрать

Для сборки разработчику нужны Windows x64, Node.js 26, npm и интернет **только на этапе сборки**. На ПК посетителя Node.js и установка браузера не нужны.

```powershell
& { Set-Location "$env:USERPROFILE\Navikultura"; npm.cmd install --no-audit --no-fund; if($LASTEXITCODE){throw 'npm install'}; npm.cmd run check; if($LASTEXITCODE){throw 'npm check'}; npm.cmd install --prefix desktop --no-audit --no-fund; if($LASTEXITCODE){throw 'Electron install'}; npm.cmd run stage --prefix desktop; if($LASTEXITCODE){throw 'Desktop stage'}; npm.cmd run test --prefix desktop; if($LASTEXITCODE){throw 'Desktop tests'}; npm.cmd run package:win --prefix desktop; if($LASTEXITCODE){throw 'Portable EXE build'}; Get-ChildItem .\desktop\dist\Navikultura-*-Windows-x64.exe | Select-Object FullName,Length }
```

В GitHub Actions workflow `Windows Portable EXE` на `windows-latest` создаётся сборочный артефакт `Navikultura-Windows-portable-exe` (срок хранения 30 дней). CI скачивается как ZIP, **внутри только один EXE**. Для локального билда нет необходимости в GitHub.

Неподписанный EXE может вызвать предупреждение Microsoft SmartScreen; для распространения на предприятии подпишите бинарник доверенным сертификатом кода. Не отключайте Windows Defender/SmartScreen для обхода предупреждений.

## Приёмка сенсорного оборудования

1. Запустить на Windows 10/11 x64 с подключенным сенсорным монитором; проверить открытие сразу на весь экран.
2. На чистом Windows-профиле ввести пароль **пальцами** через встроенную клавиатуру первого запуска.
3. Войти в админку; при касании поля ввода Windows OSK должна открыться. Не должно требоваться mouse/physical keyboard. Проверить RU/EN, backspace, верхний регистр.
4. Во всех 8 разделах вертикально пролистывать страницу пальцем. Горизонтальный жест (сдвиг `90px+`) между блоками должен переключать разделы, не срабатывать в документах, картах, iframe, видео и на кнопках.
5. На афишах горизонтальный свайп переключает афиши, вертикальное касание не меняет страницу.
6. Открыть PDF: пролистывать внутри встроенного PDF; открыть карту и перемещать карту без переходов между разделами.
7. Открыть видеоплеер: воспроизведение и управление сенсором, после закрытия плеер останавливается.
8. Muzaticket: явно вызвать Windows OSK кнопкой. **Оплату проверить на тестовом событии**, sandbox iframe может иметь ограничения платёжного оператора.
9. Закрыть приложение в обслуживании через `Ctrl+Shift+Q` и подтверждение; для реального публичного терминала задействовать выделенную Windows kiosk/Assigned Access конфигурацию.
10. Проверить сохранение афиш/тем/документов после перезапуска и подмены EXE более новой версией.
11. Проверить 1920×1080, 1366×768, Windows масштаб 125–150%, мультитач и Windows Touch Keyboard.

## Ограничения безопасности и совместимости

- Portable EXE рассчитан на **Windows 10/11 x64**, а не любой Linux/macOS PC.
- Автономный EXE не содержит корпоративных данных из игнорируемого `content/` и исходных планов Visio/памяток, отсутствующих в Git. При сборке на ПК разработчика файлы из `apps/web/public` будут включены, если они уже присутствуют. На сборочном GitHub-раннере приватных данных нет.
- Тесты CI не заменяют физическую проверку сенсорного оборудования и билетов.
- Полный экран Electron — это приложение, не принудительная защита Windows: для публичного киоска Windows Assigned Access и ограниченная учётная запись остаются важными.
- Windows Portable EXE распаковывает часть библиотек при запуске во временную папку. Это один распространяемый файл, но не один процесс и не постоянная работа без распаковки.
